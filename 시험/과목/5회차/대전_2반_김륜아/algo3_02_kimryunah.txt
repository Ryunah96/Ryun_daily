1. 정수 n에 대한 다음 명제에 대해 대우를 쓰고, 대우를 이용하여 명제를 증명하시오.
    명제 : 3n + 5가 홀수이면 n은 짝수이다.

    -> 대우 : n이 짝수가 아니면 3n + 5가 홀수가 아니다.
    -> n이 짝수가 아닌 홀수이므로 n = 2k-1으로 둘 수 있다.
    -> 3n + 5 = 3(2k-1) + 5 = 6k + 2 이다.
    -> 6k + 2는 2로 나눈 나머지가 0이므로 짝수임을 알 수 있다.
    -> 대우가 성립하므로 주어진 명제는 참이다.

2. 입력의 크기 n에 대한 어떤 코드의 연산량이 다음과 같을 때, 빅오표기법으로 복잡도를 나타내시오. (풀이도)
    T(n) = T(n-1) + 1, T(0) = 1

    -> T(n) = T(n-1) + 1
            = (T(n-2) + 1) + 1
            = T(n-2) + 2
            = T(n-3) + 3
            ...
            = T(0) + n
            = 1 + n

    -> T(n) = n + 1 임을 알 수 있다.
    -> 복잡도는 O(n) 임을 알 수 있다.
